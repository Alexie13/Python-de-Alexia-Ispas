Introducere în Python

Python este un limbaj de programare de nivel înalt, interpretat, orientat pe obiecte și cu o sintaxă simplă și clară care îl face ușor de învățat și de utilizat.

Creat de Guido van Rossum și lansat pentru prima dată în 1991, Python a devenit unul dintre cele mai populare limbaje de programare din lume datorită versatilității și lizibilității sale.

Ușor de învățat

Sintaxa clară și lizibilă face ca Python să fie ideal pentru începători.

Versatil

Python poate fi folosit în dezvoltarea web, machine learning, analiză de date, automatizări și multe altele.

Comunitate activă

Instrucțiuni de bază în Python

Python folosește o sintaxă simplă care facilitează programarea. Iată câteva instrucțiuni fundamentale:

Variabile și Tipuri de date

# Variabile
nume = "Ana"    # string
varsta = 25     # integer
inaltime = 1.75 # float
student = True  # boolean

# Afișare variabile
print(f"Nume: {nume}, Vârstă: {varsta}, Înălțime: {inaltime}m, Student: {student}")

Structuri de control

# Condiționarea if-else
varsta = 18
if varsta >= 18:
    print("Ești major")
else:
    print("Ești minor")

# Bucla for
for i in range(5):
    print(f"Numărul {i}")

# Bucla while
count = 0
while count < 3:
    print(f"Count este {count}")
    count += 1

Funcții

# Definirea unei funcții
def salut(nume):
    return f"Salut, {nume}!"

# Apelarea funcției
mesaj = salut("Maria")
print(mesaj)

Lucrul cu liste

Listele sunt una dintre cele mai folosite structuri de date în Python: 

# Crearea unei liste
fructe = ["măr", "banană", "portocală", "struguri"]

# Accesarea elementelor
print(fructe[0])  # Primul element: măr
print(fructe[-1]) # Ultimul element: struguri

# Iterarea prin listă
for fruct in fructe:
    print(fruct)

# Adăugarea unui element nou
fructe.append("kiwi")

# Verificarea existenței unui element
if "banană" in fructe:
    print("Avem banane!")

Structura programelor Python

Un program Python are de obicei următoarea structură:

1. Importuri

# Importarea modulelor
import math
import random
from datetime import datetime

2. Definirea constantelor și variabilelor globale

# Constante
PI = 3.14159
GRAVITY = 9.81

# Variabile globale
app_name = "Calculator Python"
version = "1.0"

3. Definirea claselor și funcțiilor

# Definirea unei clase
class Calculator:
    def __init__(self, nume):
        self.nume = nume
        
    def adunare(self, a, b):
        return a + b
        
    def scadere(self, a, b):
        return a - b

# Definirea funcțiilor
def salut_utilizator(nume):
    return f"Bun venit, {nume}!"

4. Codul principal

# Codul care se execută când rulezi scriptul
if __name__ == "__main__":
    print(f"Aplicație: {app_name} v{version}")
    
    nume_utilizator = input("Introdu numele tău: ")
    mesaj = salut_utilizator(nume_utilizator)
    print(mesaj)
    
    # Creare obiect Calculator
    calc = Calculator("Calculator simplu")
    
    # Utilizare metode
    rezultat = calc.adunare(5, 3)
    print(f"5 + 3 = {rezultat}")

  • │ └── 📁 subpackage/
